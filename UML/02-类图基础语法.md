# 02 · 类图基础语法

> 本节补充类框、可见性、多重性等。  
> **关系线型请看** → [01-类之间的关系.md](./01-类之间的关系.md)

---

## 1. 类框（Class Box）三段式

```text
┌─────────────────────┐
│     ClassName       │  ← 类名（抽象类可写 <<abstract>>）
├─────────────────────┤
│ - field1: Type      │  ← 属性（成员变量）
│ + field2: Type      │
├─────────────────────┤
│ + Method(): void    │  ← 方法
│ # ProtectedMethod() │
└─────────────────────┘
```

**UE 常见写法**：类名带 `U`/`A`/`F` 前缀，如 `UGameplayAbility`、`FGameplayAbilitySpec`。

---

## 2. 可见性（Visibility）

| 符号 | 含义 | C++ |
|------|------|-----|
| `+` | public | `public:` |
| `-` | private | `private:` |
| `#` | protected | `protected:` |
| `~` | package（少用） | — |

**示例**：

```text
┌──────────────────────────────┐
│   UAbilitySystemComponent    │
├──────────────────────────────┤
│ # ActivatableAbilities       │
│ + GiveAbility(Spec)          │
│ + TryActivateAbility(Handle) │
└──────────────────────────────┘
```

---

## 3. 多重性（Multiplicity）

标在关联/聚合/组合线的 **两端**，表示数量。

| 写法 | 含义 |
|------|------|
| `1` | 恰好 1 个 |
| `0..1` | 0 或 1 个 |
| `*` 或 `0..*` | 任意多个（含 0） |
| `1..*` | 至少 1 个 |
| `n..m` | n 到 m 个 |

**示例**：

```text
UAbilitySystemComponent  1  ◆──  *  FGameplayAbilitySpec
                         │       │
                    一个 ASC    多个 Spec
```

---

## 4. 角色名（Role Name）

在线条旁标注「以什么身份引用」：

```text
Player ── currentTarget ──> AActor
Spec   ── ability        ──> UGameplayAbility
```

---

## 5. 抽象类与接口

**抽象类**（有实现也可有纯虚）：

```text
┌────────────────────────┐
│ <<abstract>>           │
│   UGameplayAbility     │
├────────────────────────┤
│ + ActivateAbility()    │
└────────────────────────┘
```

**接口**（纯契约，UE 里常是 `I` 前缀）：

```text
┌────────────────────────────┐
│ <<interface>>              │
│   IAbilitySystemInterface  │
└────────────────────────────┘
```

实现关系：类 `- - - - ▷` 接口（虚线 + 空心三角）。

---

## 6. 注释与约束

**Note（注释框）**：虚线框 + 折角，解释非显而易见的设计。

**Constraint（约束）**：`{ordered}`、`{unique}` 等，标在多重性旁。

---

## 7. 五句速记

1. 类框三段：名、属性、方法  
2. `+ - #` 对应 public / private / protected  
3. 多重性标在线两端：`1`、`*`、`0..1`  
4. 抽象类写 `<<abstract>>`，接口写 `<<interface>>`  
5. 角色名写在线上，说明「怎么引用」
